<objective>
Build the Task 2 EDA notebook `task2_linking/eda.ipynb` (D-01, D-03) on the DWI 1846/1850 parquet. It shows the column overview, measures how stable the free/enslaved flag, owner fields, surnames, island and birthplace are from 1846 to 1850, estimates age noise from unique-name anchors, puts the blocking-window trade-off on one screen, and profiles households. It ends with "Facts for open decisions" for the blocking window width and feature weights. Phase 1 decides none of them.

Purpose: Phase 3 records the window width from this evidence (ROADMAP Phase 1 criteria 4 and 5, Phase 3 criterion 1).
Output: `task2_linking/eda.ipynb` committed WITHOUT outputs. The executed copy is written to the gitignored rendered dir (`data/rendered/task2_eda.ipynb` plus a local `task2_eda.html` review copy). Plan 01-04 commits outputs after the D-02 human gate.

**Data-handling rule (CLAUDE.md, D-02):** this is FamilySearch partner data. Never print record-level data into the transcript or any cell output: no rows, no `.head()`, no samples, no anchor rows, no household ids, and no owner names anywhere. While debugging, inspect schemas, shapes, null counts and aggregated tables only. Never run nbconvert with in-place execution in this plan.
</objective>
